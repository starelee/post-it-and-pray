# post it and pray

포스트잇/책상 테마의 할 일 관리 웹앱. 빌드 스텝 없이 `index.html` 하나로 동작하는 순수 HTML/CSS/JS 앱.

## 보드 구성

- **gotta do... (today)** — 오늘 할 일. 체크해도 당일 자정까지는 취소선만 그어진 채 그대로 남아있고, 다음날 앱을 열 때 자동으로 `done` 아카이브로 넘어감.
- **waiting...** — 회신/응답 대기 중인 일. "완료" 개념 자체가 없음(체크박스 대신 항상 보이는 `←` 버튼으로 today로 되돌리기만 가능).
- **scheduled** — 날짜가 지정된 할 일 저장소(someday 포스트잇 안, 기본 접힘). 오늘 마감/지난 마감 항목은 여기 대신 today's list(정상 항목 또는 "oops, still here" 아래)에 표시됨.
- **someday...** — 날짜 없는 언젠가 할 일(someday 포스트잇 안, 기본 접힘). 날짜를 지정하면 scheduled로 이동.
- **done (리갈패드)** — 완료 항목 아카이브. 월별(이번 달 기본 펼침) → 날짜별로 그룹핑. 항목별로 "↻ 다시 쓰기"(새 날짜로 scheduled에 독립 복제) / 🗑️ 삭제 가능.

## 키보드 단축키

### 어디서나 (입력창/textarea에 포커스가 없을 때만)

| 키 | 동작 |
|---|---|
| `n` | today 새 항목 입력창 포커스 |
| `w` | waiting 새 항목 입력창 포커스 |
| `s` | someday 새 항목 입력창 포커스 (접혀있으면 자동으로 펼침) |
| `d` | done 아카이브(리갈패드) 패널 열기/닫기 토글 |

### 각 보드 새 항목 입력창 안에서

| 키 | 동작 |
|---|---|
| `Enter` | 입력한 텍스트를 새 항목으로 등록 |
| `Shift+Enter` | 입력한 텍스트를 새 항목으로 등록하고, 곧바로 그 항목의 하위 항목 입력을 열어서 포커스(이어서 하위 항목을 치고 `Enter`로 계속 추가 가능) |
| `Alt+D` | 이번 세션에 그 입력창으로 마지막에 등록한 항목의 날짜 피커 오픈 (waiting은 날짜 기능이 없어서 무시됨) |
| `Alt+E` | 이번 세션에 그 입력창으로 마지막에 등록한 항목의 긴급(urgent) 표시 토글 |

`Alt+D`/`Alt+E`는 일반 타이핑(대문자 D/E 포함)과 절대 겹치지 않도록 `Shift` 대신 `Alt`를 씀 — 물리 키(`e.code`) 기준으로 감지해서 키보드 레이아웃과 무관하게 동작.

## 데이터 저장 & 동기화

- 기본은 브라우저 `localStorage`(게스트 모드, 기기별로 로컬 저장).
- Google 로그인 시 Supabase(`postit_data` 테이블, 로그인한 유저 id로 자기 자신의 행에만 접근)에 동기화됨. 로그아웃하면 다시 로컬 전용으로 동작.
- 자세한 저장 데이터 구조는 [`SCHEMA.md`](./SCHEMA.md) 참고.

## 개발

빌드/설치 과정 없음 — `index.html`을 브라우저로 열거나 아무 정적 서버로 서빙하면 끝(예: `python3 -m http.server`).
